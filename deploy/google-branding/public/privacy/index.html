Политика конфиденциальности

Эта политика описывает обработку данных внутренним приложением RTM Education Next. Для вопросов и запросов на удаление данных пишите на aiapprtm@gmail.com.

Какие данные получает приложение

Приложение получает из Битрикс24 идентификатор, имя, рабочие сведения сотрудника и данные, необходимые для ролей, назначений, уведомлений и проверки обучения. Для выбранных редактором материалов сервер использует Google Docs API и Google Sheets API с разрешениями только на чтение. Он получает содержимое, идентификатор файла и технические сведения документа или таблицы, к которым служебному Google-аккаунту предоставлен доступ. Google-аккаунт ученика для этого не требуется.

Для чего используются данные Google

Содержимое документов и таблиц используется только для отображения учебных статей сотрудникам с правом доступа и для сохранения текста опубликованной редакции статьи. Метаданные каталогов могут использоваться при однократном импорте структуры Базы знаний. Данные Google не используются для рекламы, продажи или обучения моделей ИИ.

Хранение и защита

Сервер может сохранять текстовый снимок Google-материала в опубликованной редакции статьи, а также названия, описания и ссылки импортированных элементов Базы знаний. Данные об обучении и доступе хранятся в базе приложения; резервные копии создаются для восстановления. Ключ доступа Google хранится на сервере в закрытом файле и не передаётся в браузер. Доступ к статьям и учебным данным проверяется сервером по правам сотрудника.

Передача данных

Материалы доступны только сотрудникам организации, которым предоставлены права в приложении. Приложение обменивается необходимыми данными с Google API для чтения материалов и с Битрикс24 для входа и рабочих уведомлений. Данные размещаются на сервере приложения и не продаются сторонним организациям. Передача также возможна, если этого требует закон.

Срок хранения и удаление

Опубликованные редакции и результаты обучения хранятся, пока они нужны организации для обучения и учёта. Доступ к материалу может быть прекращён администратором; удаление исходного документа в Google выполняется его владельцем отдельно. Запрос на удаление или исправление данных можно направить на адрес выше. Организация рассматривает запрос после проверки полномочий; резервные копии удаляются по циклу их хранения. Отзыв доступа к Google-аккаунту прекращает новое чтение, но уже опубликованные снимки удаляются отдельно по запросу.

Изменения политики

При изменении порядка работы с данными эта страница будет обновлена с новой датой действия.
