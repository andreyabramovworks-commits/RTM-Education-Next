Условия использования

RTM Education Next предназначено для внутреннего обучения сотрудников RTM Group через Битрикс24. Доступ предоставляется только пользователям, которым организация назначила соответствующие права.

Использование материалов

Курсы, статьи, документы, таблицы и медиа применяются для рабочих задач организации. Пользователь обязан соблюдать права на материалы и правила доступа организации. Редактор должен добавлять Google-документы и таблицы, на чтение которых у организации есть разрешение. Приложение не меняет исходные файлы Google.

Роли и учётные записи

Вход осуществляется через Битрикс24. Объём доступных действий определяется ролью и правами на конкретные материалы. Пользователь отвечает за сохранность своей учётной записи и не должен обходить ограничения доступа.

Доступность и изменения

Администратор может изменять учебные материалы, назначение курсов и доступ к ним. Работа приложения зависит от доступности Битрикс24, Google API и сервера приложения. По вопросам работы или прекращения доступа обращайтесь на aiapprtm@gmail.com.
