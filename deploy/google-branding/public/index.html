RTM Education Next

Приложение для обучения сотрудников RTM Group внутри Битрикс24: курсы, статьи Базы знаний, назначения, тесты и проверка ответов.

Как используются Google Docs и Google Sheets

Редакторы добавляют в статьи разрешённые документы и таблицы Google. Сервер приложения читает их с доступом только для чтения, чтобы показывать материалы сотрудникам, которым предоставлен доступ к статье. При публикации редакции статьи может сохраняться текстовая копия документа или таблицы для истории обучения.

Приложение не запрашивает доступ к Google-аккаунтам учеников. Доступ сервера Google настроен для отдельного служебного аккаунта.

Основное приложение доступно авторизованным сотрудникам через портал Битрикс24. Вопросы о работе приложения и данных: aiapprtm@gmail.com.

Перед использованием ознакомьтесь с политикой конфиденциальности и условиями использования.
