# Статус MVP

Первая локальная итерация: каталог черновиков курсов, поиск, описание, одноуровневая программа, перенос элементов между разделами и предпросмотр.

Данные хранятся только в localStorage браузера. Сервер, авторизация, кампании, редакторы статей и тестов, Google Docs и интеграции пока не подключены. Реальные данные сотрудников здесь использовать нельзя.

Запуск: `npm install`, `npm run dev`. Проверки: `npm run build`, `npm run lint`.

Источник продуктовых правил: `../RTM-Education-Next-spec/docs/CURRENT_MVP_BASELINE.md`.
