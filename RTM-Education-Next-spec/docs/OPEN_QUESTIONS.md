# Открытые вопросы RTM-Education-Next

Только вопросы ниже остаются нерешёнными. Закрытые решения находятся в `DECISIONS.md`. До решения действуют безопасные границы; старые правила Базы знаний не возвращаются.

## До реализации затронутой функции MVP

| ID | Этап | Вопрос | Безопасная граница | Блокирует |
|---|---|---|---|---|
| OPEN-034 | Тесты | Считать ли начатую, но не отправленную попытку использованной при закрытии браузера или истечении времени? | Сохранять попытку и серверный таймер | Политику расхода попыток |
| OPEN-035 | Прогресс | Как считать процент при нуле обязательных элементов и освобождениях? | Не показывать ложные 100%; освобождение отдельно от завершения | Формулу прогресса |
| OPEN-036 | Отчёты | Как фиксировать агрегаты закрытой кампании после изменения живого курса? | Сохранять события и технический снимок состава | Итоговую статистику |
| OPEN-037 | Тесты | Как проходит тест только со свободными ответами? | После отправки ожидать проверки | Точный переход |
| OPEN-039 | RUTUBE | Какие события доступны у целевых приватных роликов? | Не включать автоматический зачёт просмотра без проверенных событий | Автоматический процент |
| OPEN-040 | Курс | Название и точная семантика первой активации курса? | Сохранение, активация и кампания раздельны | Текст UI и статус |
| OPEN-042 | Импорт | Какой формат исходной Google таблицы и как сопоставить строки с Google file ID при однократном импорте? | Идемпотентный импорт после проверки источника; не создавать дубли и не вводить прямой URL в курсе | Импорт начального каталога |

## Закрыто новым решением 25.11.2026
